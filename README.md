# WebSec Start

Учебная платформа по веб-пентесту для начинающих. Интерфейс на русском, узбекском и английском.

- **Теория по OWASP Top 10:2025** — 10 тем: объяснение, разбор кода «уязвимо / исправлено», как искать и как исправлять.
- **CTF-лаборатории** — по одной на тему (31 шаг всего). Сценарий, список целей, подсказки без готовых команд и терминал, в котором нужно самому найти флаг.
- **Бонус-цепочки** — две лаборатории, где несколько слабостей идут подряд (бэкап → вход → IDOR; хранимый XSS → кража сессии).
- **Терминал-симулятор** — `curl` (и `wget`/httpie), `nmap`, `whatweb`, `ffuf`, `nikto`, `sqlmap`, `testssl.sh`, `trivy`, `git show`, `cat`, `nano`, `echo`, `ls`, `login`. Реальная сеть не используется: все ответы выдуманные.
- **Каталог инструментов** — для каждого: установка, пошаговая инструкция, примеры команд. Burp Suite и ZAP — графические, для них подробная инструкция вместо терминала.
- **Аккаунты и прогресс** — регистрация и вход, прогресс привязан к аккаунту.

## Важно знать

- Это **статический сайт без бэкенда**: один файл `index.html` (HTML, CSS и JS внутри). Сборка не нужна.
- Аккаунты и прогресс хранятся в `localStorage` браузера. Между устройствами и браузерами они **не синхронизируются**, а пароль хранится без криптографии — это тренировочный профиль, а не защищённая учётная запись.
- Общего рейтинга (scoreboard) нет: для него нужен бэкенд (например, Supabase или Firebase).
- Единственная внешняя зависимость — шрифты Google Fonts (JetBrains Mono, Onest). Без интернета сайт работает, но со стандартными шрифтами.

## Публикация: GitHub → Netlify

1. Создайте пустой репозиторий на GitHub (без README и .gitignore — они уже есть в проекте).
2. В папке с файлами выполните:
   ```bash
   git init
   git add .
   git commit -m "WebSec Start: first version"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
   git push -u origin main
   ```
3. На [app.netlify.com](https://app.netlify.com): **Add new site → Import an existing project → GitHub** → выберите репозиторий.
4. Build command оставьте пустым, Publish directory — `.` (корень). Настройки возьмутся из `netlify.toml`.
5. Нажмите **Deploy**. Каждый следующий `git push` в `main` будет выкатываться автоматически.

Свой домен: Site configuration → Domain management → Add custom domain.

Без Git: на странице Netlify Sites перетащите папку проекта в область «Drag and drop your site folder here».

## Где что менять в `index.html`

Файл большой, поэтому ищите по именам:

| Что менять | Что искать |
|---|---|
| Тексты интерфейса и теория (ru / uz / en) | `TEXT.ru =`, `TEXT.uz =`, `TEXT.en =` |
| Шаги, команды и вывод лабораторий | `const LAB_DEFS` |
| Описания шагов, подсказки, итоговый текст | `const LAB_TEXT` |
| Бонус-цепочки | `const BONUS` и записи `b01`, `b02` в `LAB_DEFS` / `LAB_TEXT` |
| Список инструментов и примеры команд | `const TOOLS` |
| Цвета и шрифты | блок `:root{ ... }` в начале `<style>` |
| Ответы терминала на общие команды | `function cmdOutput` |

Чтобы добавить шаг в лабораторию, добавьте объект в `steps` в `LAB_DEFS` и по одной строке в `steps` и `hints` для каждого языка в `LAB_TEXT`. Количество элементов должно совпадать. Флаг должен быть в выводе последнего шага: лаборатория засчитывается, когда выполнен последний шаг.

## Правила использования

Всё, что здесь изучается, применяйте только к системам, на тестирование которых у вас есть письменное разрешение: свои стенды, CTF-площадки, bug bounty. Сканирование чужих сайтов без разрешения — уголовно наказуемо.
